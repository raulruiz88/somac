# Directrices del Proyecto SOMAC

## Flujo de Trabajo de Git (Automático)
- Cada vez que completes y verifiques cualquier cambio o tarea solicitada por el usuario en el proyecto:
  1. Preparar los cambios: `git add .`
  2. Confirmar con un mensaje descriptivo: `git commit -m "<mensaje claro y en español>"`
  3. Enviar a GitHub: `git push origin main`
  4. Indicar brevemente al usuario el commit realizado y confirmar que quedó subido a GitHub.
